Query 4

Division Query

Find staff who are responsible for all treatment plans.

SQL Preview

SELECT DISTINCT sr.SID FROM SpecialistResponsible sr WHERE NOT EXISTS (SELECT tp.TID FROM TreatmentPlan tp WHERE NOT EXISTS (SELECT sr2.SID FROM SpecialistResponsible sr2 WHERE sr2.SID = sr.SID AND sr2.TID = tp.TID))
Query 5a

Aggregation - COUNT

Count the number of rows in a table. Type COUNT in the function field.

SQL Preview

SELECT COUNT(...) AS CountResult FROM ...
Query 5b

Aggregation - MAX

Find the highest value in a field. Type MAX in the function field.

SQL Preview

Query 6

SQL Preview

SQL Preview
