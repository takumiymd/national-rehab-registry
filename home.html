Patient Tracking

Staff Management

Research Data

Provides useful data for health professionals and researchers studying addiction recovery.

About This Project

This system was built for CPSC 2221 - Database Systems as a group project. It uses PHP and MySQL to manage patient data at a rehabilitation center. The database is private and only accessible to authorized healthcare professionals.
