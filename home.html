About This Project

This system was built for CPSC 2221 - Database Systems as a group project. It uses PHP and MySQL to manage patient data in a rehabilitation setting.

The registry is intended for authorized healthcare professionals and researchers, supporting both patient management and data-driven rehabilitation analysis.
